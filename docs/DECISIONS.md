# Decisions

Record of choices made where the spec was ambiguous, impossible, or where the environment differed.

| Date | Question | Decision | Reason |
|---|---|---|---|
| 2026-10-16 | Local PHP is 8.2 (and 8.4); spec says 8.3. | Docker image and CI use PHP 8.3. Local development/tests run on the machine's default PHP 8.2, which Laravel 11 supports. | No PHP 8.3 binary on the build machine; nothing in the code base depends on 8.3-only syntax. |
| 2026-10-16 | Breeze ships registration and email verification. | Registration route, view and tests removed. Email verification removed: users only ever exist through an accepted invitation, which proves ownership of the email. | Spec section 8.1: invite-only, no public registration. |
| 2026-10-16 | Breeze ships a "delete my account" form. | Removed. Accounts are deactivated by admins instead of deleted by the user. | Audit trail and tenant admin control (section 8.1). |
| 2026-10-16 | Redis client. | `predis/predis` (pure PHP) instead of the `phpredis` extension. | The extension is not available in the local PHP; predis works everywhere, including CI. |
| 2026-10-16 | Google Fonts vs Bunny Fonts. | Public Sans is loaded from Google Fonts as the spec says, with system-ui fallback. | Spec section 11. |
| 2026-10-16 | Test database. | Tests run against MySQL 8 (`127.0.0.1:3307`, database `emotion_test`, root/secret) via Docker, both locally and in CI. | Spec section 2: tests use MySQL to match production JSON column behaviour. |
| 2026-10-16 | TOTP 2FA. | Out of scope for the MVP (spec 8.1). Login throttling (5/min) from Breeze is kept. | Spec. |
| 2026-10-16 | `GET /forms` items do not carry a workspace name, but the picker must show one. | When "All workspaces" is selected the catalog lists workspaces and calls `GET /forms?workspace_id=…` once per workspace (first 200 forms each), caching the result for 60 s. | Keeps the API call count low (Typeform allows ~2 req/s) while still showing the workspace column. |
| 2026-10-16 | "max 3 retries" vs Laravel `Http::retry($times)` which counts total attempts. | The client passes `max_retries + 1` so a failing call is attempted 4 times (1 + 3 retries). | Matches the spec wording literally. |
| 2026-10-16 | Carry-over for sections the admin created in the editor (no Typeform `ref`). | Admin-created sections get a synthetic `source_ref` of `admin-xxxxxxxx` and are copied into every new version together with the fields moved into them. | Spec 6.4 keys carry-over on `source_ref`; without one, admin sections would vanish on the next Typeform edit. |
| 2026-10-16 | Detecting "the admin had moved a field" (6.4 step 4). | The previous version's definition is re-parsed; if the stored section differs from where parsing would have placed the field, it counts as an admin move and is kept when that section still exists. | Otherwise a Typeform-side move of a question could never take effect. |
| 2026-10-16 | Field `display_order` after the admin reorders fields inside a section. | On save the editor renumbers `display_order` globally following section order then field order. | Keeps one simple ordering for the detail page and CSV columns. |
| 2026-10-16 | Section ordering on new versions. | Sections matched by `source_ref` keep the parsed order; admin-created sections are appended. | Simplest rule consistent with 6.4, which only requires name and weight to carry over. |
| 2026-10-16 | `--version` for `evaluations:rescore` clashes with Symfony's global `--version`. | The option is `--on-version=N`. | Console framework limitation. |
| 2026-10-16 | Webhook route without session/CSRF. | `routes/webhooks.php` is loaded through `withRouting(then:)` with no middleware group, so it never gets the `web` stack; only `throttle:webhooks` applies. | Spec 5.6 (no session, excluded from CSRF, 120/min per IP). |
| 2026-10-16 | Info values from hidden fields vs. mapped questions. | A mapped question wins; hidden values (`hidden.branch`, …) only fill keys the answers did not provide. | Deterministic and keeps the admin's mapping authoritative. |
| 2026-10-16 | Responses API pagination end condition. | Stop when a page is empty, has no last token, or returned fewer than 1000 items; hard cap 200 pages. | Avoids infinite loops on API quirks; 200 000 responses per sync is far above expected volumes. |
| 2026-10-16 | Section widgets must group across form versions whose section ids differ. | Section averages group by the snapshot `section_name` and are ordered by the current version's section order; question widgets group by Typeform field id and take the title from the newest version. | Renames carry over, so names are stable; ids are not. |
| 2026-10-16 | Full-page Livewire components mounted without a route parameter receive an empty `Hospital` from the container. | `mount(?Hospital $hospital = null)` treats a non-existing model as "no hospital" and falls back to the user's own hospital. | Lets one component serve both `/dashboard` and `/hospitals/{uuid}/dashboard`. |
| 2026-10-16 | CSV column name clash: the overall column and a section literally named "Overall". | Section columns are prefixed `Section: … %`. | Keeps headers unique for spreadsheet users. |
| 2026-10-16 | `JSON_EXTRACT` returns binary-collated strings in MySQL, making `LIKE` case-sensitive. | Search lowers both sides. | Spec 9.2 expects a plain text search. |
| 2026-10-16 | Where to store the workspace → hospital mapping. | Two nullable columns on `hospitals` (`typeform_workspace_id`, `typeform_workspace_name`). | One workspace per hospital is enough for the MVP; a pivot table would be speculative. |
| 2026-10-16 | Branch records when the source is free text. | Branches are `firstOrCreate`d by exact (trimmed, 120-char) name per hospital. Spelling variants become separate branches, as the spec warns; a dropdown or hidden field is recommended in the UI. | Spec section 17. |
| 2026-10-16 | Who is the actor for automatic links? | `linked_by` is null and the audit entry carries `automatic: true`. | Scheduled jobs have no user. |
| 2026-10-16 | CSP strictness vs Livewire 3 / Alpine. | `script-src 'self' 'unsafe-inline' 'unsafe-eval'` (Alpine evaluates expressions, Livewire injects inline scripts), styles from self + Google Fonts, `frame-ancestors 'none'`, `object-src 'none'`; Vite dev-server origins are added in the `local` environment only. Extra script origins via `CSP_EXTRA_SOURCES`. | A nonce-based policy would require patching Livewire's script injection; this is the strictest policy the stack supports without that. |
| 2026-10-16 | "Exceptions reported without request bodies". | `withExceptions()->context()` overrides the request body context with `[omitted]`; Laravel does not log bodies by default, this guards against future context additions. | Spec section 12. |
| 2026-10-16 | `--large` seeding speed. | Above 2 000 evaluations per form the seeder runs the pure `ScoringEngine` and bulk-inserts submissions, answers and section scores in 500-row batches instead of going through the ingestor. | 50 000 evaluations through the per-row ingestor would take ~20 minutes; bulk mode takes a few minutes and produces identical data shapes. |
| 2026-10-16 | Visual direction: the spec's "clinical and calm" header layout vs the owner's request for a modern dashboard like their sample (sidebar, KPI tiles, heat-map). | Rebuilt the shell as a dark sidebar with an accent blue, KPI tile row, Chart.js trend/donut, HTML bar lists, facility ranking and a touchpoint heat-map. Spec palette kept for text, surfaces and RAG; every colour still carries its number. Categorical series colours validated with the data-viz palette checker. | Owner request after seeing the first version; sample provided as reference. |
| 2026-10-19 | Owner wants to host on SiteGround shared hosting: no Docker, no Redis, no resident queue worker. | Production profile `deploy/siteground/env.example` uses `database` for sessions, cache and queue (the `cache_locks` table backs the ingestion lock) and two every-minute cron jobs (`schedule:run`, `queue:work database --stop-when-empty --max-time=50`). Release bundles (`deploy/build-release.sh`) ship `vendor/` and `public/build/` because the host has no Node. Docker/Redis remain the reference setup in `docker-compose.yml`. | Verified end to end locally in this mode; webhook latency becomes ≤ 60 s instead of seconds, which the owner accepted for shared hosting. |
